B.

claude --print -p "Analyze PR #123..." --json-schema schema.jso

C.

claude --exec "analyze PR #123" --format=json

D.

claude review --pr 123 --json

A
Explanation
Claude Code CLI does not have an --output-format flag. Setting response formatting requires passing a JSON Schema definition or explicit instructions.
B
Explanation
The --print (or -p ) flag runs Claude Code in non-interactive / programmatic headless mode, and --json-schema enforces structured output that strictly validates against a provided JSON schema file or string, ensuring downstream parser compatibility.
C
Explanation
--exec and --format=json are invalid CLI parameters for invoking Claude Code headlessly for schema-enforced analysis.

Explanation
While /code-review exists as an interactive slash command inside Claude Code, claude review is not a standalone CLI sub-command with a --json output flag for custom inline-commenting scripts.
💡 Key Learning Point

Non-interactive Execution ( -p / --print ): Suppresses terminal interactivity, execution prompts, and spinner animations, directing output straight to stdout . This ensures downstream scripts receive predictable keys (e.g., file , line , severity , comment ) for posting inline PR comments via the GitHub or GitLab API.
